# Консольный симулятор службы доставки

Практическая работа № 1 по объектно-ориентированному программированию. Программа хранит заказы и список курьеров в оперативной памяти. При каждом запуске список заказов пуст.

## Запуск

Из папки проекта выполните команды с Python 3.10 или новее. Дополнительные пакеты не нужны.

```text
python main.py
python -m unittest discover -s tests -v
```

## Меню

1. **Создать заказ и добавить позиции.** Укажите имя и телефон клиента, адрес, затем введите название, количество и цену каждой позиции. Для самовывоза адрес можно оставить пустым. В цене разрешены точка или запятая и до двух знаков после них.
2. **Показать список заказов.** Программа выводит позиции, суммы, способ доставки, курьера и статус каждого заказа.
3. **Выбрать способ доставки.** Введите номер заказа, затем выберите способ. Программа покажет стоимость доставки, общий итог и ориентировочный срок.
4. **Назначить курьера.** Для стандартной или экспресс-доставки выберите курьера из списка. В начале сеанса доступны три курьера.
5. **Изменить статус заказа.** Выберите новый статус. После успешного перехода программа покажет обновлённую информацию о заказе.
6. **Завершить работу.**

## Тарифы и статусы

| Способ | Стоимость | Примерный срок |
| --- | --- | --- |
| Стандартная доставка | 300 руб. Бесплатно при сумме товаров от 3 000 руб. | 48 ч |
| Экспресс-доставка | 500 руб. за первую единицу товара и 30 руб. за каждую следующую | 12 ч |
| Самовывоз | 0 руб. | 2 ч до готовности к выдаче |

- **Курьерская доставка** — Новый → Подтверждён → В доставке → Выполнен.
- **Самовывоз** — Новый → Подтверждён → Готов к самовывозу → Выполнен.
- Новый или подтверждённый заказ можно отменить. Статусы «Выполнен» и «Отменён» конечные.
- Для подтверждения нужен выбранный способ доставки, для отправки курьерского заказа — назначенный курьер. Позиции и способ доставки можно менять, пока заказ новый. Если переключить новый заказ на самовывоз, назначение курьера снимается.

Для демонстрации создайте заказ на две книги по 120,50 руб. и один блокнот за 75 руб. Выберите стандартную доставку. Сумма товаров составит 316 руб., итог — 616 руб., срок — 48 часов. Назначьте курьера, подтвердите заказ, переведите его в доставку и завершите. Для самовывоза создайте второй заказ с пустым адресом и после подтверждения выберите «Готов к самовывозу».

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `main.py` | Точка входа. Создаёт курьеров и сервис, запускает меню. |
| `console.py` | Читает и проверяет ввод, вызывает сервис, выводит меню и карточки заказов. |
| `models.py` | `Customer` хранит контакты, `Courier` — номер и имя, `OrderItem` — товар, количество и цену. `Order` контролирует состав, доставку и статус, а `OrderStatus` задаёт перечень статусов. |
| `delivery.py` | `DeliveryMethod` задаёт общий контракт. `StandardDelivery`, `ExpressDelivery` и `PickupDelivery` реализуют расчёт тарифа и срока. |
| `order_service.py` | `OrderService` хранит заказы и курьеров в словарях, находит их по номеру и передаёт изменения заказу. |
| `tests/` | `test_orders.py` проверяет модель, тарифы и сервис. `test_console.py` запускает программу с подготовленным вводом и проверяет вывод. `__init__.py` позволяет обнаруживать тесты из корня проекта. |

## Где применяется ООП

- **Инкапсуляция.** `Order` хранит список позиций, способ доставки, курьера и статус во внутренних атрибутах. Методы проверяют изменения, а свойство `items` возвращает кортеж позиций.
- **Наследование.** Три варианта доставки наследуются от абстрактного `DeliveryMethod`.
- **Полиморфизм.** Заказ вызывает `calculate_cost()` и `estimate_hours()` у выбранного способа. Каждый класс сам определяет результат.
- **Композиция.** Заказ содержит клиента, позиции и способ доставки. В курьерском сценарии к заказу также привязывается курьер.
